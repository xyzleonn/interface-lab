# Changelog

Notable project changes in Interface Lab.

## 0.1.0

- Added a dashboard, Theme Studio, application preferences, and an isolated Design Token Studio with token presets and CSS/JSON export.
- Added an 11-component Playground with editable variants, sizes, interactive preview states, saved presets, and HTML/CSS/React-TSX export.
- Added curated built-in font selection and local custom font uploads stored in IndexedDB.
- Added dark and light appearances, custom accent colors, responsive layouts, keyboard interactions, and reduced-motion support.
- Added Node.js regression tests and Playwright Chromium end-to-end coverage.
